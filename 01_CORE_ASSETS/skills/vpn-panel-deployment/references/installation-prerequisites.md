# Installation Prerequisites — جمع‌آوری اطلاعات اولیه

## ⚠️ مهم‌ترین مرحله قبل از نصب!

قبل از شروع هرگونه نصب، **حتماً** از کاربر اطلاعات زیر رو بگیر:

### پیام به کاربر:
```
سلام عزیزم! ❤️ برای نصب ربات به چند تا چیز نیاز دارم، لطفاً بفرست:
۱. توکن ربات تلگرام (از @BotFather)
۲. آیدی عددی تلگرامت (از @userinfobot)
۳. نام رباتت بدون @ (مثلاً MyBot)
```

### اطلاعات مورد نیاز:

| آیتم | توضیح | مثال |
|------|-------|------|
| **توکن ربات** | از @BotFather بگیر | `123456:ABC-DEF...` |
| **آیدی عددی ادمین** | از @userinfobot بگیر | `123456789` |
| **نام ربات** | بدون @ | `MyBot` |

### بعد از گرفتن اطلاعات:
```
عالیه! 🎉 الان شروع میکنم به نصب.
فقط یادت باشه این اطلاعات رو نگه داری:
- توکن: [توکن]
- آیدی: [آیدی]
- نام: [نام]
```

### چرا این مرحله مهمه؟
- بدون توکن ربات کار نمیکنه
- بدون آیدی ادمین، ادمین نمیتونه ربات رو مدیریت کنه
- این اطلاعات در فایل config.php استفاده میشن

### نکته امنیتی:
- هرگز توکن و پسورد رو در ترمینال نمایش نده
- این اطلاعات رو فقط در فایل config.php ذخیره کن
