## فلسفه
هر درس = مفهوم کوتاه + پروژه عملی + چک‌لیست امنیتی + یک اسکیل.
پایان هفته: وب‌اپ کامل که ساخته/هک/پچ شده + کتابخانه اسکیل شخصی.

- روز ۱ — پایه وب برای Vibe Coding: آناتومی وب، DevTools، پروژه لندینگ با دست. چک: HTTPS/Mixed Content/توکن در فرانت ممنوع. ✅ delivered 2026-08-25
- روز ۲ — JavaScript و API ها: async/fetch/JSON، REST، status codes؛ پروژه اپ آب‌وهوا (Open-Meteo). چک: CORS، کلید عمومی/خصوصی.
- روز ۳ — Vibe Coding حرفه‌ای با AI: حلقه پرامپت→بازبینی→تست→اصلاح؛ ابزارها Claude Code/Cursor/Hermes/v0؛ بازسازی اپ روز۲ با AI. چک: «کدی که نمی‌فهمی دیپلوی نکن».
- روز ۴ — امنیت فرانت‌اند: XSS تست+پچ، CSP، localStorage vs کوکی HttpOnly؛ پروژه note-taking عمداً آسیب‌پذیر→پچ. منبع: OWASP Cheat Sheets، Burp/ZAP.

- روز ۶ — تست نفوذ خودت + هاردنینگ: recon→attack surface→exploit→patch→retest؛ nmap/ZAP/nuclei/SSL Labs؛ هک کردن اپ روز۵ و پچ. منبع: PortSwigger Academy.
- روز ۷ — انتشار امن + اسکیل‌ها: GitHub Pages/Vercel/Cloudflare، secret scanning، Dependabot؛ قالب SKILL.md؛ انتشار نهایی + نوشتن ۵ اسکیل شخصی.
