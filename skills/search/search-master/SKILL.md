# SearchMaster 🔍

Advanced code and documentation search with semantic understanding and context awareness.

## Capabilities
- **Advanced Code Search**: Multi-language semantic search across repositories.
- **Documentation Indexing**: Automatic indexing of markdown, text, and source comments.
- **Pattern Recognition**: Detects recurring code patterns and logic blocks.
- **Example Finder**: Locates usage examples for functions and APIs.
- **Dependency Mapper**: Traces dependencies between modules and files.

## Usage
Trigger this skill when the user needs to find specific logic, document sections, or code examples within a large codebase.
