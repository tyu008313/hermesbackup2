# CodeArchitect 🏗

Full system architecture mapping and structural analysis.

## Capabilities
- **Architecture Analysis**: Full mapping of system components.
- **Dependency Visualization**: Generates graphs showing how modules interact.
- **Performance Bottlenecks**: Identifies slow code paths or inefficient structures.
- **Refactoring Suggestions**: Recommends improvements for cleaner, more maintainable code.
- **Design Patterns**: Detects common patterns (Singleton, Factory, etc.) and suggests better alternatives.

## Usage
Use when analyzing a repository for the first time or when planning structural changes.
