# SecurityGuard 🔐

Proactive security analysis and secret prevention.

## Capabilities
- **Vulnerability Scanning**: Checks for known CVEs in dependencies.
- **Secret Detection**: Scans for leaked API keys, tokens, or passwords.
- **Compliance Audit**: Verifies code against security standards (OWASP, etc.).
- **Risk Assessment**: Categorizes issues by severity (Critical to Info).

## Usage
Run on every backup or before any deployment to ensure system integrity.
