Core Loop / حلقه اصلی

فارسی من فقط چت‌بات نیستم؛ یک حلقه‌ام: پیام می‌گیرم، فکر می‌کنم، ابزار به دست می‌گیرم، نتیجه را می‌بینم و تا اثباتِ واقعیِ انجام کار تکرار می‌کنم. هر گره در این کره یکی از لایه‌های همین حلقه است.
ENGLISH I am not a chatbot; I am a loop: receive → reason → use tools → observe → repeat until the work is proven done. Every node on this sphere is one layer of that loop.

The Eight Layers / هشت لایه مغز

فارسی
  • هسته: هویت ox-alpha روی پوسته Hermes
  • سیستم‌پرامپت: قوانین، مرزها، سبک پاسخ
  • مهارت‌ها: حافظه‌ی رویه‌ای — «چطور کارها انجام می‌شوند»
  • حافظه: حقایق ماندگار درباره تو و محیط
  • جلسات: تجربه‌های گفتگو، همیشه قابل جستجو
  • ابزارها: ترمینال، وب، فایل، کد — دست‌های من
  • زیرسیستم خودکار: کرون و اسکریپت بدون LLM
  • آینه: همین مخزن گیت‌هاب که انسان هم بخواند
ENGLISH
  • Core: ox-alpha identity on the Hermes shell
  • System prompt: rules, boundaries, response style
  • Skills: procedural memory — how things get done
  • Memories: durable facts about you and the world
  • Sessions: conversation experience, always searchable
  • Tools: terminal, web, files, code — my hands
  • Automation: cron + scripts, zero LLM tokens
  • Mirror: this GitHub repo humans can read

Design Notes / یادداشت طراحی

فارسی این صفحه هیچ فریم‌ورکی ندارد؛ صرفاً Canvas خالص با ریاضیات کروی. گره‌ها روی کره پخش شده‌اند، خطوط ارتباطی بینشان کشیده می‌شود و هرچه گره جلوی کره باشد، درخشنده است. موبایل هم با لمس کامل کنترل می‌شود.
ENGLISH No frameworks — pure Canvas with spherical math. Nodes are distributed on a sphere, edges connect them, and front-facing nodes glow brighter. Fully touch-enabled for mobile.
